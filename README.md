> An authentic Vedic astrology academy, horoscope consultation booking, and student enrollment management system built with React, Vite, Tailwind CSS, and a Node.js/Express REST API connected to MySQL.

---

## ✨ Features

- **Jothida Vidyalayam Academy**: Structured course catalog for Vedic astrology, Prasannam, Nadi astrology, and Vastu shastra.
- **Student Admissions & Enrollments**: Online student registration, batch selection, and student certificate tracking.
- **Horoscope & Consultation Appointments**: Direct consultation scheduling with expert astrologers and birth chart analysis.
- **Vidyalayam Admin Suite**:
  - `VidyalayamDashboard.jsx`: Executive overview of active students, upcoming batches, and consultation requests.
  - `VidyalayamCourses.jsx`: Course syllabus manager, fee structure editor, and batch scheduler.
  - Payment records and receipt management.

---

## 🛠️ Tech Stack & Local Setup

- **Frontend**: React, Vite, Tailwind CSS (`http://localhost:5176`)
- **Backend**: Node.js, Express, MySQL Pool (`http://localhost:5005`)

### Running Locally

```bash
# 1. Start Backend Server (Port 5005)
cd varahi_react/backend
npm install
node server.js

# 2. Start Frontend (Port 5176)
cd ../frontend
npm install
npm run dev -- --port 5176
```
